# Resume Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a single-page printable HTML resume at `resume.html` in the project root that produces a clean A4 PDF when printed from Chrome.

**Architecture:** One self-contained HTML file with all CSS inlined in a `<style>` block. No JS, no external dependencies, no build step. Print CSS uses `@page { size: A4; margin: 0; }` so the user only needs to open the file and Cmd+P → Save as PDF. Screen view renders a centered paper-look page for easy preview.

**Tech Stack:** HTML5, CSS3 (print media queries, flexbox), Georgia serif font (system font, no import needed)

**Spec:** `docs/superpowers/specs/2026-03-21-resume-design.md`
